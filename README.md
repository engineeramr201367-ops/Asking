# سوبر جري — Super Run 🍄

لعبة منصّات (Platformer) على طراز **ماريو**، مبنية بـ HTML5 Canvas + JavaScript خالص (بدون أي مكتبات).
تعمل مباشرة في متصفح الجوال بأزرار لمس، ويمكن **تثبيتها كتطبيق** على شاشة الهاتف الرئيسية (PWA) وتشتغل حتى بدون إنترنت.

## طريقة اللعب 🎮
- **الهدف:** اجمع العملات 🪙، اقفز فوق الأعداء 👾، ووصّل إلى العلَم 🚩 في نهاية كل مرحلة.
- عندك **3 محاولات** (قلوب ❤️) و **5 مراحل** متدرجة الصعوبة.
- **على الجوال:** أزرار `◀` `▶` للحركة و `⤴` للقفز.
- **على الكمبيوتر:** الأسهم أو `A/D` للحركة، و`مسافة` / سهم لأعلى للقفز.
- انطح الصناديق `؟` من تحت للحصول على عملات إضافية.

## القوى الخاصة 🍄🔥
- **فطر 🍄** (من صناديق `؟`) يكبّر الشخصية.
- **زهرة نار 🔥** تمنحك رمي كرات نار (زر 🔥 على الشاشة، أو `F`/`X` على الكيبورد) تقتل الأعداء من بعيد.
- الضرر متدرّج: نار ← كبير ← صغير ← موت، مع لحظة حماية بعد الضربة.

## المميزات ✨
- 🔊 **مؤثرات صوتية** مولّدة برمجياً (قفز، عملة، دهس عدو، فوز/خسارة) مع زر كتم `🔊`.
- 🏆 **حفظ أعلى نتيجة** تلقائياً على جهازك (localStorage) وتظهر في شاشة البداية والنهاية.
- 🗺️ **5 مراحل** متدرّجة الصعوبة.
- 📱 يعمل باللمس + الكيبورد، ويُثبَّت كتطبيق ويشتغل بدون إنترنت.

## التشغيل محليًا 💻
اللعبة ملفات ثابتة، لكن الـ Service Worker يحتاج خادمًا (مش فتح الملف مباشرة). شغّل خادمًا بسيطًا:

```bash
# باستخدام Python
python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```

أو أي خادم ملفات ثابت آخر (مثل `npx serve`).

## التثبيت كتطبيق على الجوال 📱
1. افتح رابط اللعبة في متصفح الجوال (Chrome / Safari).
2. **أندرويد:** من القائمة اختر «تثبيت التطبيق» / «Add to Home screen».
3. **آيفون:** زر المشاركة ⬆️ ثم «إضافة إلى الشاشة الرئيسية».
4. سيظهر أيقونة اللعبة على شاشتك وتفتح بملء الشاشة كتطبيق مستقل.

## الملفات 📂
| الملف | الوصف |
|------|-------|
| `index.html` | واجهة اللعبة والشاشات وأزرار اللمس |
| `game.js` | محرّك اللعبة كامل (فيزياء، أعداء، مراحل، رسم) |
| `manifest.json` | إعدادات تطبيق الويب التقدمي (PWA) |
| `sw.js` | Service Worker للعمل بدون إنترنت |
| `icon.svg` | أيقونة التطبيق |

## أفكار للتطوير مستقبلًا 💡
- إضافة أصوات ومؤثرات صوتية.
- حفظ أعلى نتيجة (High Score) في `localStorage`.
- المزيد من المراحل وأنواع أعداء جديدة.
- شخصيات وقدرات إضافية (زهرة النار مثلًا).
